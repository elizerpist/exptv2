# Fluvi category catalog mapping

Version: `1`

The visual source of truth is the Spendee worktree:

- palette: `docs/prototypes/color_lab.html` and
  `docs/prototypes/mind_global_rail_stage_layout_reference.html`;
- icon ordering: `lib/features/transactions/slots/category_icon_manager.dart`;
- original vector assets: `assets/icons/lucide/`.

The source palette contains three exact CSS stops. Fluvi calls the first and
last stops A/B while retaining the source middle stop and the source angle so
the visual definition is not approximated. Room stores only the stable IDs.

The source list also contains utility icons and ten later category options.
Those are intentionally not assigned to the existing `icon_01…icon_50`
contract. They can be added only as a versioned catalog extension, never by
reusing an existing ID.

Uncategorized is explicitly pinned to `color_01` + `icon_01`; it does not
depend on catalog ordering. No archive category is introduced. Backups and
checkpoints remain the recovery mechanism for destructive changes.
