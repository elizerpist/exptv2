# Balance V2 Implementation Plan

> **For agentic workers:** Execute inline; this task shares the Balance shell
> state and must not be split across concurrent writers.

**Goal:** Add a selectable Balance V2 where the five FastInfo islands become
rich, taller pages of the existing detail carousel without moving the
post-carousel Balance layout.

**Architecture:** Keep `SpendeeBalanceDashboard` as the single shell owner.
Add a V2 presentation and a dedicated V2 carousel/page renderer in the
existing Balance-card module, so the normal four-page carousel and its V3
contracts remain unchanged. All models are derived from `BalanceRenderFrame`.

**Tech Stack:** Flutter/Dart; existing Balance frame, ticking viewport,
CategoryIconManager/central category resolver, GitHub Android workflow.

## Global constraints

- No screenshots, Playwright or Puppeteer.
- Run Flutter tests/analyze only inside Ubuntu proot.
- Preserve the dirty worktree and stage only Balance V2 files.
- Build APK only on GitHub Actions after focused verification.
