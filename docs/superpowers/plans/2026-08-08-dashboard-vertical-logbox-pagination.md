1. **Lock baseline and add red ownership tests.** Keep the frozen-hash manifest. Add tests demonstrating that a page append must not republish the rail-visible frame or request the rail cache, and that a committed page cannot be visible until its full render resources are ready.
2. **Split page result from visible frame.** Introduce immutable committed-page metadata/results and revise the keyset decoder/repository boundary to return only one page. Preserve the native keyset request and isolate decode. Do not touch prepared index/presentation/visible store/rail code.
3. **Implement the committed vertical owner.** Add `CommittedLogViewportController` and its bounded page cache with exact generation/cursor deduplication, stale discard, page-state transitions, current±2 retention, eviction, page/layout byte/row counters, and atomic publish notification.
4. **Wire the application boundary.** Seed the vertical owner from every committed visible preview, route near-end requests through it, and invalidate it on exact scope/revision/navigation changes. Keep the existing explicit paging controller as the sole repository-read authority, but make it deliver complete page results to the vertical owner instead of publishing a `DashboardVisibleFrame`.
5. **Virtualize the stable render surface.** Feed it a committed vertical snapshot and map physical scroll to logical rows/page cache, including groups/headers across page boundaries. Keep the one CustomPaint/ScrollController identity, paint/semantics only visible+overscan and diagnose vertical failures separately.
