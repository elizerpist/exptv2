# Budget preview/vector publication acceptance checklist

## Architecture card

- **Single write paths:** `BudgetTargetAvatarRail._onPreviewChanged` is the sole
  semantic crossing source. It publishes both `DashboardBudgetPresentationController`
  and the existing `DashboardBudgetLogboxDrilldownCoordinator`; the latter delegates
  to `DashboardCoreController`, which remains the only Ephemeral Focus publisher.
- **Reusable renderer:** dynamic donut SVG sources are generated by the existing
  `BudgetDistributionSvgSourceGenerator`; the existing `PreparedVectorAssetAtlas`
  `PictureInfo → CustomPainter` pattern is adapted as a bounded, frame-owned picture
  bank. Widgets own only hit testing and paint the supplied immutable resource.
- **Header identity:** `DashboardBudgetPresentationController` derives one typed
  `analysisScopeLabel` from its exact visible frame; the header consumes that immutable
  projection and never reads navigation directly.
