# Stage 2 empty state and paging checklist

Reference screenshot: `/storage/emulated/0/Pictures/Screenshots/Screenshot_20260720-210611.png`

User-approved direction: Stage 2 should not show a sparse empty vendor page when the selected category has no spend. If the selected category has spend, Stage 2 has the shared category chart plus the vendor page. If the selected category has no spend but the active period has spend elsewhere, Stage 2 has only the shared category chart. A full empty-state panel is reserved for periods with no spend anywhere.

Interpretation note: the user said "hónapban"; implementation should apply this to the currently displayed active period/window in the header, such as `Június 2026`, unless the user later narrows it to monthly-only.

Supersedes: the earlier `VND-001` idea in `docs/superpowers/checklists/2026-07-20-avatar-carousel-snap-vendor-empty.md` that asked for a blank vendor chart when a selected category had no scoped vendor data.
