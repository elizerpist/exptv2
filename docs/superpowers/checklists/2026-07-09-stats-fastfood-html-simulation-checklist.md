- Header magnet marker: marker x-position is `rail.x + rail.w * clamp(score / 100, 0, 1)`. Marker uses `scoreColor(score)`, shadow `rgba(15,23,42,.22)`, blur `5`, offsetY `1`, colored rounded rect `6px` wide plus white center rect `2.5px` wide. Keep this score-positioning logic.
- Score color scale: `0..45` is red `#ef4444`, `45..60` is amber `#fbbf24`, `60..100` is green `#22c55e`. Main neutral y-line is at score `50`, color `rgba(251,191,36,.50)`, line width `1` in the primary Soft band chart.
- Primary score math, dense mode: use active scope days where `scopeAmount > 0 && scopeAmount >= threshold`. Crop graph from first qualifying day to last qualifying day; do not draw empty year tail. If no qualifying day exists, score is one centered point `100`. For more than `12` qualifying days, use centered `31`-day rolling windows clipped to the active scope range. Count rolling occurrences and rolling amount sum separately, smooth both with `ema(dynamicEmaPeriod(focusScopeDays))`, normalize each to `0..100` by its own max, compute `pressure = occurrence * 0.5 + amount * 0.5`, then `score = clamp(100 - pressure, 0, 100)`.
- Primary score math, sparse mode: if qualifying day count is `<= 12`, use real hit days only. Each score point is `100 - (qualifyingAmount / amountMax * 100)`, clamped to `0..100`, positioned by the real date inside `graphDays`. This avoids fake dense curves with sparse samples.
- Primary score rendering: Soft band background gradient is top green `rgba(34,197,94,.13)`, mid green `rgba(34,197,94,.04)`, neutral amber `rgba(251,191,36,.08)`, lower red `rgba(239,68,68,.04)`, bottom red `rgba(239,68,68,.13)`, rounded radius `8`. Draw one smooth score path clipped into score zones with width `3.1` and alpha `0.96`; use `lineCap` and `lineJoin` `round`. Endpoint dot radius is `4.3`.
- Primary chart axes: y labels `100`, `50`, `0` use `6.8px`, weight `700`, `gray500`, positioned at `chart.x - textWidth - 5`. Month labels use `7.4px`, weight `700`, `gray500`, y `chart.y + chart.h + 11`, x clamped to `[chart.x, chart.x + chart.w - textWidth]`. Month tick positions come from `monthTicksForGraphDays(graphDays)`.
- Helper chart data: `helperAmountLine` contains only real threshold-hit samples from `graphDays`; no synthetic interpolation/filler bars. Point position is the real date position inside `graphDays`.
- Helper threshold-excess math: if `threshold > 0`, compute `excess = max(0, amount - threshold)` for each real sample, `maxExcess = max(1, ...excessValues)`, `delta = excess / maxExcess * 100`. If `threshold <= 0`, fallback to min-baseline: `delta = (amount - minAmount) / maxSpread * 100`.
- Helper threshold-excess rendering: bars use `baselineMode: bottom`, color `#ef4444` for all threshold-excess bars, baseline stroke `rgba(100,116,139,.4)`, chart background `rgba(248,250,252,.72)`, radius `6`. Available bar height is `chart.h * 0.82`; `barHeight = max(1, abs(delta) / 100 * available)`. Top is `baselineY - barHeight`. Bar radius is `min(2.4, barWidth / 2)`.
- Helper bar width: if sample count `<= 12`, `barWidth = clamp(chart.w / max(points.length * 7, 18), 5, 10)`. Otherwise `barWidth = clamp(chart.w / (points.length * 1.35), 1.1, 7)`.
- Helper bar opacity: opacity follows the same normalized threshold-excess as height: `globalAlpha = clamp(0.34 + abs(delta) / 100 * 0.5, 0.34, 0.84)`. A small excess is faint; the largest visible threshold excess is strongest.
- Monthcards and threshold circles remain consistent with the current HTML/app monthcard design.
