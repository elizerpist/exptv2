## Implementation and boundaries

API35 eligible standalone ORB LIVE can reserve the first compatible inspection on the existing reader before Main adopts its wake; a staged non-touchable host and hidden generation-owned Canvas output prepare separately. The coordinator joins the current complete MAIN proof, exact host/image, authorized interaction and final system eligibility; the dedicated serial compositor lane submits direct reveal and seals/hides/unparents the exact output on withdrawal. The bounded capture retains original wake, host, output, privacy, timing and transaction evidence. Other routes retain their stock path and failed staging requests a fail-closed fallback; the complete device privacy contract remains unqualified. The direct renderer does not establish physical first/last pixels merely from its transaction or fence. This is a source implementation and an experimental binary, not a claim that every eligible wake uses the new route or that the phone symptom is fixed.

The selected R16 phone capture `9a34ce08-2bd5-4810-8056-f98c86341ed2` had actual DISCREET show decisions despite a full start preference. Four wake-to-decision values were 183/173/140/194 ms and decision-to-first-buffer 99/77/84/123 ms. First and last physical pixels were unobserved. Retain the original capture's 31,447-byte truncated export and unknown fifth SCREEN_ON; do not treat this small, differently disclosed sample as a matched performance comparison.
